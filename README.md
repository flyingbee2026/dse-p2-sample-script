# F5 English Paper 2 - Learning from a sample script (DSE 2022 Part B Q9)

Lesson materials (about 60 minutes) in which students learn **content** and **organisation** - not only
vocabulary - from a Level 5** sample script on the DSE 2022 Part B question *"four-day school week"
letter to the President of the PTA*.

Contents
- `F5-P2-sample-script-lesson-Students.docx` - the original cropped script pages (handwriting kept),
  plus content, organisation, language, scoring and writing tasks
- `F5-P2-sample-script-lesson-Teacher.docx` - the same, with every answer written in red in the line or
  table cell where a student would write it, plus keys, timings, the 28-slip audit table and a typed
  transcript of the script in an appendix
- PDFs of both, and a zip holding all four files.

Lesson shape: Part 1 plan the task and the content (15 min) - Part 2 read the sample pages: word counts,
content map, how each idea is elaborated, the letter's moves, topic sentences, linking words, five
advanced sentence patterns and the vocabulary bank (30 min) - Part 3 comment and score the script against
a real marker's report, correct five of the writer's 28 slips, write your own opening paragraph (15 min).
